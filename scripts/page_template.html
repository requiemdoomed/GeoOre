Read the land from orbit. Find the ore beneath it.

GeoOre maps where ore is likely to be using open satellite imagery, elevation models and geological fault maps, then grades ore quality from assay samples. No drones, no field sensors. It shows geologists where to sample next.

    Grade lab

    From assay to ore grade

    An XGBoost model sorts samples into high, medium or low grade. Choose a held-out sample to see its assay values, the model's prediction, and the elements that pushed it there (SHAP values). These are real outputs from the trained model.

    Confusion matrix

    What drives the predictions

    Mean absolute SHAP value per feature. Copper and gold lead, as expected for a Cu-Au system.

    Features

    What GeoOre delivers

    Field identification

    Iron-oxide and clay indices from Sentinel-2 or Landsat, combined with terrain and fault proximity into one score per cell.

    Grade classifier

    XGBoost predicts high, medium or low grade, cross-validated, with SHAP explanations for every sample.

    Explained heatmaps

    Each cell gets a confidence score and a sentence saying what drove its score.

    GIS exports

    GeoTIFF rasters plus GeoJSON and shapefiles for zones, targets and samples, ready for QGIS or ArcGIS.

    MeasureValue
    These scores come from the built-in demo area, where the ore bodies are known so the method can be checked. Real ground is noisier, so expect lower numbers. Use the results to decide where to sample, not as a replacement for sampling.
    Get started

    Run it on your machine

    # 1. get the code
$ git clone https://github.com/<your-username>/GeoOre.git
$ cd GeoOre
$ pip install -r requirements.txt

# 2. run the full pipeline (results go to outputs/)
$ python scripts/run_pipeline.py

# 3. open the interactive app
$ streamlit run app.py

# 4. run the tests
$ pytest
    Use real imageryInstall earthengine-api, run earthengine authenticate, then choose Google Earth Engine in the app sidebar.
    Bring your own dataUpload an assay CSV and a fault-line GeoJSON from your geological survey in the sidebar.
    Take it to GISThe Export tab bundles rasters, GeoJSON and shapefiles into one zip.
